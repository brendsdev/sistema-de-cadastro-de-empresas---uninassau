# Sistema de Cadastro de Empresas

Sistema desenvolvido em Python para consulta de CNPJ via API da Receita Federal e cadastro em banco de dados local.

## Tecnologias
Python
PyQt
SQLite

## Funcionalidades
Consulta automática de CNPJ
Cadastro de empresas
Login de usuário
Armazenamento em banco SQLite

## Como executar

1. Instalar dependências
pip install -r requirements.txt

2. Executar o sistema
python main.py
